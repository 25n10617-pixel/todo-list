GitHub Pages 배포 방법

1. 이 폴더 안의 index.html 파일을 GitHub 저장소 최상위(root)에 업로드하세요.
2. 기존 todo-checklist-fixed.html 파일은 삭제하지 않아도 됩니다.
3. 저장소의 Settings > Pages에서 Source를 Deploy from a branch로 설정하세요.
4. Branch는 main, Folder는 /(root)로 선택하고 Save를 누르세요.
5. Actions에서 Pages 배포가 성공했는지 확인한 뒤 아래 주소로 접속하세요.
   https://25n10617-pixel.github.io/todo-list/

주의: ZIP 전체를 저장소에 그대로 올리지 말고, ZIP 압축을 푼 뒤 index.html 파일만 저장소 최상위에 올리세요.

기능: 할 일 추가(버튼/Enter), 마감일, 분류, 중요도, 완료 체크, 필터, 삭제, 진행률 계산, 브라우저 자동 저장.
